# Windows AI helper provenance

The helper directly pins Windows App SDK `2.5.1`, CsWinRT `2.3.1`, and Windows SDK .NET reference pack `10.0.28000.87`. The x64 and ARM64 lockfiles capture the stable dependency graph, including Windows AI and Search `2.5.5`, Windows ML `2.1.94`, and Windows App SDK Runtime exactly `2.5.1`. Component versions are not release-channel labels. Runtime binding uses the restored Runtime package's constants and requires a real stable runtime.

The restored SDK package's unmodified license is preserved at `licenses/Windows-App-SDK.txt`; the AI and Search packages carry the same license. Windows ML's separate terms are preserved at `licenses/Windows-ML.txt`, and CsWinRT's MIT notice remains at `licenses/CsWinRT-MIT.txt`. The two Microsoft notice files retain their exact upstream bytes. Redistribution remains subject to the applicable package terms and release requirements.

The staged helper contains no Aion SDK, Aion model/framework, experimental speech projection, or engineering-preview notice. Native Aion reports `unavailable/aion_no_stable_contract` on every architecture because no verified redistributable stable contract exists. No Aion sample-derived binding survives in the helper; the removed sample notice does not govern the current implementation.

Stable App Content Search is a Limited Access Feature. Microsoft must issue a feature-specific ID, token and attestation to the app owner. No verified stable activation contract or owner grant is available, so the helper blocks index operations with `accessRequired/app_content_access_not_provisioned` after identity and runtime checks. The separate language-model token grants no search access.

[Microsoft release channels](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/release-channels), [Windows App SDK 2.0 release notes](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/release-notes/windows-app-sdk-2-0), [the stable NuGet package](https://packages.nuget.org/packages/Microsoft.WindowsAppSDK/2.5.1), [LimitedAccessFeatures](https://learn.microsoft.com/uwp/api/windows.applicationmodel.limitedaccessfeatures), and the [App Content Search tutorial](https://learn.microsoft.com/en-us/windows/ai/apis/app-content-search-tutorial) provide the published contracts. Microsoft source locations include [Windows App SDK](https://github.com/microsoft/WindowsAppSDK), [CsWinRT](https://github.com/microsoft/CsWinRT), and [Windows App SDK samples](https://github.com/microsoft/WindowsAppSDK-Samples). The restored package metadata and lockfiles determine the compiled dependency graph.
