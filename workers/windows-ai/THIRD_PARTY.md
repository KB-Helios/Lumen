# Windows AI helper provenance

The helper uses Microsoft SDK projections and adapts the process-scoped Aion dependency binding from [Microsoft's Aion sample](https://github.com/microsoft/Aion-Instruct-Preview-Sample/blob/main/unpackaged-console/FrameworkDependency.cs). The sample's MIT notice is preserved at `licenses/Aion-Sample-MIT.txt`. The SDK's own terms are distinct from the sample license.

Exact direct packages are Windows App SDK `2.5.4-experimental`, CsWinRT `2.3.1`, Windows SDK .NET reference pack `10.0.28000.87`, and, only for ARM64, Aion SDK `1.0.0`. Architecture-specific NuGet lockfiles capture the full dependency graph. Microsoft source locations are [Windows App SDK](https://github.com/microsoft/WindowsAppSDK), [CsWinRT](https://github.com/microsoft/CsWinRT), and [Windows App SDK samples](https://github.com/microsoft/WindowsAppSDK-Samples).

`sdk-lock.json` pins the [official Aion release](https://github.com/microsoft/Aion-Instruct-Preview-Sample/releases/tag/v1.0.0.0) URLs and GitHub-reported SHA-256 digests. ARM64 staging checks both the local feed archive and the restored NuGet archive before compilation. Staging never downloads the 1.39 GB framework/model MSIX or runs upstream setup scripts.

The Windows AI and Search packages use Microsoft's engineering-preview terms, preserved in `licenses/Windows-App-SDK-Engineering-Preview.txt` and `licenses/Windows-App-SDK-Search-Preview.txt`. These terms restrict live operating use and redistribution unless Microsoft permits it under another agreement. This implementation and its staged artifacts are for the approved local preview/testing scope; a production distribution requires a suitable Microsoft agreement or migration to redistributable stable SDK contracts. The sample's MIT license does not grant rights to redistribute Microsoft's separate SDK/runtime/model packages.

Authoritative API references consulted via Context7 and Microsoft Learn: [Windows AI catalogue](https://learn.microsoft.com/en-us/windows/ai/apis/), [Phi Silica access and readiness](https://learn.microsoft.com/en-us/windows/ai/apis/phi-silica), [OCR](https://learn.microsoft.com/en-us/windows/ai/apis/text-recognition), [AppContentIndexer](https://learn.microsoft.com/en-us/windows/ai/apis/app-content-search-tutorial), [Agent Launchers](https://learn.microsoft.com/en-us/windows/ai/agent-launchers/agents-get-started), and [Windows ML](https://learn.microsoft.com/en-us/windows/ai/new-windows-ml/overview). Several sample names differ from current SDK projections; helper compilation uses the pinned current contracts, including `ActionRuntime.ActionCatalog`, action overload invocation, progress-bearing `GenerateResponseAsync`, and asynchronous OCR.
